# Proyecto TXT a CSV

# Descripcion

Este codigo realizado con el lenguaje Python realiza una lectura a archivo .TXT el cual contene datos dummy.

- RFC
- Razón Social
- Código Postal

Los cuales se convertira estos datos en un archivo csv para poder leerlos en Python.

---

## Archivos del proyecto

- datos.txt
- main.py
- conversion.csv

---
## Explicaciòn de la ejecuciòn
El archivo txt debe estar separado por comas la informaciuon

Ejemplo:

XAXX010101000,EMPRESA ALFA SA DE CV,01000

Posteriormente este se convertira en un archivo.csv
